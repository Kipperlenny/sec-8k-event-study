# Changelog

## 1.0.0 (2026-09-18)

First release. Three event classes (8-K Items 2.05, 2.06, 4.02), 983 events, 2005 to 2025; per-class
aggregates from our runs of 2026-09-05 (2.05, 2.06) and 2026-09-18 (4.02); `sec_events` package
(loader, price sources, event-study engine, comparison helper), notebook, five offline tests. Schema
`item_filter_v1`; ticker mapping `edgar_current`.
